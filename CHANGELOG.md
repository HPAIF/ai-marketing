# Changelog

All notable changes to the AI marketing member. Versions follow semver: patch = fixes and
wording, minor = new skill / workspace files, major = breaking workspace change.
Entries that need a workspace change list a **Migration** step; `setup` (upgrade mode) applies it.

## 0.1.1 — 2026-11-23
- Rule "Be concise": shortest answer that keeps all important information (warnings, numbers,
  dates, sources, decisions); long only when the content needs it.

## 0.1.0 — 2026-11-22
- First public release — a basic version, to be specialised later.
- Agent `marketing`, rules (`RULES.md`), skills: setup, icp-personas, positioning, content-plan,
  copywriting, launch-plan, channel-review, log-job, improve.
- Workspace folder `ai-team/marketing/` (contract v1): ICP and personas (owned by marketing,
  read by sales), positioning, claims register, content plan, channels, history, drafts,
  research, digests, inbox. The workspace is found in the project folder or any parent folder.
- Templates: draft, research memo, launch plan, channel test.
- Self-improvement: `learnings.md` + `improve` (anonymised, founder-approved pull requests).
- Frameworks and sources summarised in `docs/research.md`.
