# Claims register

> Every factual claim used (or proposed) in marketing: numbers, performance, comparisons,
> "first/only/best", customer results, testimonials, logos, security/compliance statements.
> Written by `copywriting`, `positioning` and `log-job`. Never delete a row; change the status
> and add a dated note. Keep the column order — the session hook reads the Status column.
> - **Source / company fact:** link + date checked, or a workspace file / record / "founder, date"
> - **Risk:** low (plain fact) · medium (numbers, comparisons) · high (superlatives, health/finance/security, testimonials, competitor named)
> - **Lawyer check:** not needed · asked `<date>` · `lawyer:R-xxxx` (answer) · founder decided `<date>`
> - **Status:** `ok` · `needs-source` · `needs-lawyer` · `withdrawn`
