# Drafts

One file per draft: `DR-XXXX-short-slug.md`, from the plugin's `templates/draft.md`. Front-matter
`status:` drives the session hook:

- `draft` — being written, or blocked on a source / lawyer check
- `ready` — claims checked; waiting for the founder's approval
- `approved` — the founder approved the text; **the founder publishes it**
- `published` — the founder said it went out (date and where are recorded)
- `dropped` — not used

The AI marketing member never publishes, posts, sends or schedules a draft. Never delete a draft;
change its status.
